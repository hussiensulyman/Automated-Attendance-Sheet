# Automated Attendance Sheet

A Flask-based web application for automating attendance tracking using facial recognition.

## Features
- Automates attendance with OpenCV and face_recognition.
- Stores data in sample_attendance.csv and SQLite.
- Includes sample_dataset/ and sample_attendance.csv for testing.

## Installation
1. Clone: `git clone https://github.com/hussiensulyman/Automated-Attendance-Sheet.git`
2. Setup: `python -m venv venv; source venv/bin/activate; pip install -r requirements.txt`
3. Run: `python app.py`

## Usage
- Use sample_dataset/ for testing.
- Original student data excluded for privacy.
